# 答辩问答准备

> 原则：先给结论，再给证据，最后说边界。不会的问题直接说“还没验证”，不要编。

## 1. 这和普通 RAG / 单 Agent 问答有什么区别？

普通 RAG 是“检索→拼接→生成”，回答是一段话，引用通常挂在末尾。我们是**任务级协作**：Leader 先产出计划，应用侧校验后提交给原生任务板，Research 和 Engineering 被调度器分别拉起，各自回传结构化结果；每条 `fact` 结论必须引用该任务**实际检索到并保留**的证据，否则被改标为 `[unverified]`。

单 Agent 也能拆步骤，但分工、依赖和完成判定都在一段上下文里，出了错无法定位是谁、哪一步。我们把这些变成可检查的记录。

## 2. 引用怎么保证不是模型编的？

两层：

- **集合校验**：引用 id 必须落在该任务 execution 的检索返回集内；语料里有但没被检索到的证据不算支撑。
- **结构验收**：任务成功 + 有 claim + fact 有引用 + 引用在集合内，四条同时满足才算通过；报告逐项标出未通过的验收。

仍有限制：它保证“引用的确是检索到的原文”，不保证“原文一定支持这句话”的语义层面——那需要 reviewer 或人工复核，我们把它列在限制里。

## 3. 冲突检测会不会误报、漏报？

会。规则刻意做窄：只对**同句式、不同来源、不同数值**的 fact 生成候选，不做语义判断。所以：

- 漏报：语义矛盾但句式不同，检不出来；
- 误报：句式碰巧相同但语境不同，可能给出低价值候选。

我们选择“宁可漏报，不自动裁决”。报告并列双方原文和定位，由人判断。当前语料没有真实冲突对，演示时面板是空状态，我们如实说明。

## 4. 为什么固定两个专业成员？不是说要动态扩缩容吗？

MVP 先固定 Leader + Research + Engineering，把委派、门禁、引用做扎实。动态成员需要队列压力、预算、draining 和成员生命周期，属于后续阶段；我们不把“预留了接口”说成“已经实现”。

## 5. 为什么公网不开放文件和命令工具？

公网链接给评委用，开放 shell/文件等于把任意代码执行暴露出去。Claude Code 那类工具跑在用户本机、用用户权限，场景不同。我们的取舍是：公网只读语料 + 安全工具面；通用工具能力放到本地/管理员模式，赛后做。

## 6. 数据安全和隐私怎么保证？

- 公网只开放预置语料，不接受上传；
- 会话用签名 HttpOnly Cookie，运行按会话隔离；
- 模型密钥只在服务端环境变量，不写进 payload、不返回给前端；
- 工具面在请求层和执行层双重拒绝，记录被拒绝的调用。

## 7. 模型幻觉怎么办？

不能消除，只能约束和暴露：

- 事实必须引用；
- 未通过校验的结论改标 `[unverified]` 并排除出交付证据；
- 证据不足时报告写明“未找到”，而不是补一个像样的答案。

## 8. 为什么选教育？这和个性化学习、智能助教有什么关系？

我们做的是**教师侧的智能助教**：在引入 AI 教学工具前，依据教育政策和 AI 教育指南做合规评估，输出可回查的清单。它服务的是教学评估与教研，不是学生答疑。新补的语料里有《中小学人工智能通识教育指南》《中小学生成式人工智能使用指南》《教师数字素养》，正好覆盖“教师怎么合规用 AI”。

边界：目前不做个性化学习推荐，也不做课堂互动。

## 9. 知识库只有 25 份文件，够吗？

不够厚，但够支撑一个垂直切片。25 份 / 380 块覆盖教育法、学位法、教师数字素养、两份 AI 教育指南、教育评价改革、招生与教辅、AI 治理法规。课程方案与课程标准是扫描 PDF、本机无 OCR，没有强行塞进来；未成年人学校保护规定也还没拿到全文。这些都在材料里写明。

## 10. 成本和延迟怎么样？

真实回合通常数分钟，取决于模型和检索轮次。我们记录了回合截止时间、并发和每日配额；没有把 token 成本做成实时看板，这是已知缺口。

## 11. 平台或模型挂了怎么办？

- 单容器镜像，换平台只换部署配置；
- 失败态可见：超时、空闲、崩溃都写明确原因，不伪装成完成；
- 语料在首次启动时自动重建；
- 风险：未挂持久卷，重启后运行历史会丢。

## 12. 商业化/推广怎么做？

先做“可审计交付”这个差异点，面向学校、教育机构和合规部门。工作区是“语料 + 提示词 + 访问范围”的配置，换领域不需要改代码。收费模式可以按席位或按报告，但还没有验证，不在答辩里承诺。

## 13. 和 JoyCode 平台是什么关系？

JoyCode 是大寨提供的模型调用平台。我们的作品可以接入它的模型服务，但运行不依赖它；作品里说明关系即可，不宣称深度集成。

## 15. 如果现在让你重做，你会改什么？

先做用户访谈再写代码。现在的工程验证很扎实，但“老师到底怎么用”是最后才补的；如果重来，会先拿 3 个真实教研场景验证问题定义，再决定知识库和界面。

## 16. 打开链接为什么先出现腾讯云的“页面访问提示”？

这是 CloudBase 对默认测试域名的合规中间页，不是应用故障。点一次“确定访问”即可，同一浏览器会记住。平台文档明确：移除该中间页的唯一合规途径是绑定已 ICP 备案的自定义域名；比赛期间我们使用默认域名，并在提交说明里告知评委这一步。
