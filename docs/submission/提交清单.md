## 一、PPT

- 页数：≤ **20 页**；比例 **16:9**；大小 ≤ **50MB**
- 结构（官方建议，必须逐节覆盖）：

| 章节 | 页数 | 本作品对应内容 |
|---|---|---|
| 作品背景与说明 | 1 | 政策研读的引用/冲突/验收问题；参考来源 |
| 数据来源 | 1–2 | 6 份 AI 法规 + 9 份教育政策，官方站点、时效性 |
| 知识库内容 | 1–2 | 265 块、locator、FTS5、每工作区独立库 |
| 预处理与利用 | 1–2 | 抓取→解析→切片→索引→检索流程图与工具 |
| 分析方法选择 | 1–2 | 多 Agent 分工 + 结构化门禁；为什么不用单 Agent |
| 问题理解与逻辑论证 | 2–3 | 任务图、引用漏斗、真实运行数据、思维导图 |
| 创新点展示 | 1 | 结论级引用、冲突保留、原生委派 |
| 独特视角 | 1 | 教育 × 合规审核交叉；“可审计 AI” |
| 结果解读 | 1–2 | 真实回合报告、耗时/证据数、应用价值 |
| 问题与建议 | 2–3 | 已知限制 + 优化路线 |
| 风险识别与应对 | 1–2 | 数据安全、幻觉、成本与滥用 |
| 应用对话界面 | 1 | 工作台截图与说明 |
| 提示词示例与链接 | 1 | 3 个提示词 + 输出 + 智能体链接 |
