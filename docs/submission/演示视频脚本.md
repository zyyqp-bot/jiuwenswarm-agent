## 录制要点

1. **先跑一次预热**，正式录制重新开始；不要拿旧结果冒充新运行。
2. 任务图节点出现后不要剪掉等待；中间可 2 倍速并加字幕“真实等待，未剪辑”。
3. 证据抽屉必须同时出现**正文 + 来源 + locator**，这是与普通 RAG 的分界。
4. 冲突面板若为空，照实说：“这份语料没有检出同句式不同数值的冲突，系统明确写出未发现，而不是暗示资料一致。”
5. 全程检查画面：无学校、姓名、指导教师、密码、API Key、控制台密钥页。
6. 导出参数：1080p、H.264、码率 4–6 Mbps，控制在 300MB 内。
