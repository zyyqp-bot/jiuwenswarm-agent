# 垂直语料目录

`corpus/<workspace>/` 存放该工作区的公开资料。镜像构建时整个目录复制到 `/app/corpus`，部署后由运维在容器内执行 `scripts/import_corpus.py` 建立索引。

规则：

- 只放**可公开引用**的政策、法规、标准或官方解读；不要放入内部资料或个人信息。
- 支持 `.txt`、`.md`、`.pdf`（PDF 需要可提取文本，扫描件不做 OCR）。
- 文件名会成为 `source_uri`，请用可读的正式名称，例如 `生成式人工智能服务管理暂行办法.md`。
- 修订以内容哈希判定：同一文件改内容后重新导入会替换旧块，不需要先删除。
- 公开链接不提供上传入口；新增资料必须经过 Git 提交和重新部署。

`ai-governance/` 至少放入一份文件后，工作区的检索工具才会返回证据；否则运行仍可提交，但引用校验会让结果失败。
